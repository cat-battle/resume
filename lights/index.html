🔌 Electrical Details ▶

Pro H706A — Power Specs

  • Adapter: 36V DC, 3A, 108W (indoor)
  • 2× units = ~216W max
  • 15A circuit = 1,800W capacity — well within limits
  • Adapter stays in attic, dry and protected

Prism H707B — Power Specs

  • Adapter: 36V DC, 2.3A, 72W (outdoor)
  • 2× units = ~144W max
  • Outdoor adapter — needs weatherproof housing under eave

Requirements

  • 🔒 GFCI protection required on all outdoor lighting circuits
  • Control box mounts outside under eave — verify weatherproofing
  • Run Romex from furnace circuit breaker through attic to vent exit point
  • Use junction box at vent exit; seal penetration with foam/caulk
  • Label breaker clearly after install
🛠️ Install Tips ▶
1️⃣Start at the power point (vent), work outward. Don't start in the middle.
📏Snap a chalk line along the fascia first — ensures perfectly straight runs.
🔵Press each clip ~8 seconds for VHB adhesive to bond. South/west sides get extra clips for heat expansion.
✂️Cut only at marked cut points. Never mid-segment. Measure twice.
💧Waterproof all splices, especially at corners. Use heat-shrink or Govee splice connectors.
🧪Test the full run on the ground before mounting. Much easier to troubleshoot before it's on the roof.
📱Govee app syncs both controllers together — set up same segment count so animations align.
🌡️Rated −4°F to 140°F — Eagle winters are no problem.
⚠️Furnace circuit: confirm it's not on a dedicated furnace breaker. Use a shared attic/lighting circuit if available, or add a sub-branch.
